📌 Habit Tracker Telegram Bot (v2.0)
Персональный трекер привычек с современным Menu-driven интерфейсом. Бот помогает формировать полезные привычки, визуализировать прогресс и защищает пользователя от дублирования данных.

Проект выполнен в рамках учебной работы по курсу разработки ИТ-систем.

✨ Возможности бота
✔ Умное управление привычками

Добавление через FSM: Пошаговый диалог добавления названия, категории и времени напоминания.

Категоризация: Готовые пресеты (Здоровье, Учёба, Работа и др.) для структурирования целей.

Гибкие напоминания: Установка времени в формате ЧЧ:ММ или работа в режиме «без уведомлений».

Удаление: Безопасное каскадное удаление привычки вместе со всей историей её выполнений.

✔ Интерактивный интерфейс

Reply-меню: Постоянная клавиатура с кнопками для быстрого доступа к функциям.

Inline-кнопки: Использование встроенных в сообщения кнопок для выбора привычек при отметке выполнения или просмотре статистики.

Оптимизированный UX: Бот не повторяет приветственные сообщения после каждого действия, сохраняя чистоту чата.

✔ Аналитика и защита данных

Защита от дублей: Логика базы данных не позволяет отметить одну и ту же привычку дважды в течение одного дня.

Статистика: Расчет общего количества выполнений и текущего «стрика» (серии дней без пропусков).

Визуализация: Генерация линейных графиков прогресса с помощью matplotlib.

Экспорт: Выгрузка истории в формате CSV (название, дата) для внешнего анализа.

✔ Автоматизация

Фоновые уведомления: Ежеминутная проверка базы данных и рассылка напоминаний пользователям.

🧱 Стек технологий
Python 3.13 (оптимизировано под macOS)

Aiogram 3 — асинхронный фреймворк для Telegram Bot API.

SQLite — локальная реляционная база данных.

Matplotlib — генерация графических отчетов.

python-dotenv — безопасность конфиденциальных данных.

🚀 Запуск проекта (Инструкция для macOS/Windows)
Клонировать репозиторий:

Bash
git clone https://github.com/Darina-bor/habit-tracker-telegram-bot.git
cd habit-tracker-telegram-bot
Настроить окружение:

Bash
python3 -m venv venv
source venv/bin/activate
Установить зависимости:

Bash
pip install aiogram matplotlib python-dotenv
Настроить токен:
Создать файл .env и добавить: BOT_TOKEN=ваш_токен_из_BotFather

Запустить:

Bash
python3 bot.py
