# 📌 Habit Tracker Telegram Bot (v2.0)

![Python](https://img.shields.io/badge/python-3.13-blue.svg)
![Aiogram](https://img.shields.io/badge/aiogram-3.x-orange.svg)
![SQLite](https://img.shields.io/badge/database-SQLite-lightgrey.svg)

Персональный трекер привычек с современным **Menu-driven** интерфейсом. Бот помогает формировать полезные действия, визуализировать прогресс и защищает данные от дублирования.

> Проект выполнен в рамках учебной работы по курсу разработки ИТ-систем.

---

## ✨ Возможности бота

### 🛠 Умное управление
* **Добавление через FSM**: Пошаговый диалог (Название → Категория → Напоминание).
* **Категоризация**: Готовые пресеты (Здоровье, Учёба, Работа и др.).
* **Гибкие напоминания**: Установка времени в формате `ЧЧ:ММ` или режим «без уведомлений».
* **Удаление**: Безопасное каскадное удаление привычки вместе со всей историей её выполнений.

### 📱 Интерактивный интерфейс
* **Reply-меню**: Постоянная клавиатура с кнопками для мгновенного доступа.
* **Inline-кнопки**: Использование встроенных кнопок для выбора конкретных привычек при отметке выполнения.
* **Чистый UX**: Оптимизированная логика сообщений — бот не дублирует приветствие после каждого действия.

### 📊 Аналитика и защита
* **Защита от дублей**: Логика базы данных блокирует повторные отметки одной и той же привычки в течение одного дня.
* **Статистика**: Подсчет общего количества выполнений и текущего «стрика» (серии дней).
* **Визуализация**: Генерация линейных графиков прогресса с помощью библиотеки `matplotlib`.
* **Экспорт**: Выгрузка истории в формате CSV для внешнего анализа.

## 🧱 Стек технологий
* **Python 3.13** — основной язык разработки.
* **Aiogram 3** — асинхронный фреймворк для взаимодействия с Telegram API.
* **SQLite** — локальная реляционная база данных.
* **Matplotlib** — построение графиков и визуализация.
* **python-dotenv** — безопасное хранение токенов в `.env` файлах.

##🚀 Запуск проекта

###Клонировать репозиторий:
git clone [https://github.com/Darina-bor/habit-tracker-telegram-bot.git](https://github.com/Darina-bor/habit-tracker-telegram-bot.git)
cd habit-tracker-telegram-bot

###Настроить окружение (macOS):
python3 -m venv venv
source venv/bin/activate

###Установить зависимости:
pip install aiogram matplotlib python-dotenv
Настроить токен:
Создайте файл .env и добавьте: BOT_TOKEN=ваш_токен_от_BotFather.

###Запустить:
python3 bot.py
